# 6-Домашняя работа 
## 1.Алгоритм 
1.Начало.

2.Вывод сообщения: «=== ЗАДАЧА 1: Проверка точки ===».

3.Вывод запроса: «Введите координаты точки x и y через пробел: ».

4.Ввод данных: считать значения x и y (вещественные числа).

5.Проверка условия принадлежности точки заштрихованной области:

условие 1: y >= 0 (точка находится в верхней полуплоскости, включая ось X);

условие 2: x * x + y * y <= 36.0 ;

условие 3: !(x >= 0 && (x * x + y * y <= 9.0))

итоговое условие: все три части должны выполняться одновременно (логическое «И»).

6.Ветвление:

если условие из шага 5 истинно, вывести: «Точка (x, y) ПРИНАДЛЕЖИТ заштрихованной области»;

иначе вывести: «Точка (x, y) НЕ ПРИНАДЛЕЖИТ заштрихованной области».

7.Конец.
